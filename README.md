# JULIETH_ROJAS_API_COLOMBIA.
# 🌎 Mini Portal de Colombia con API

## 📌 Descripción del proyecto

Este proyecto consiste en el desarrollo de un mini portal web informativo sobre Colombia, el cual consume datos en tiempo real desde la API pública **API Colombia**.

El objetivo principal es mostrar información relevante del país de manera dinámica utilizando JavaScript y manipulación del DOM, permitiendo al usuario navegar entre diferentes secciones mediante hipervínculos.

El portal incluye varias secciones como:

* 🏙 Departamentos de Colombia
* 👔 Presidentes de Colombia
* 📊 Información general del país

Cada sección obtiene los datos desde la API utilizando `fetch`, los procesa y los muestra de forma visual mediante tarjetas modernas con animaciones.

---

## 🎯 Objetivos del proyecto

* Consumir datos desde una API pública.
* Manipular el DOM dinámicamente con JavaScript.
* Aplicar estilos modernos con CSS.
* Implementar navegación entre páginas sin eventos JavaScript.
* Manejar errores y mostrar mensajes de carga.
* Crear una interfaz atractiva tipo página profesional.

---

## 🛠 Tecnologías utilizadas

* **HTML5** → Estructura del sitio web
* **CSS3** → Diseño, estilos y animaciones (incluyendo efectos tipo Apple)
* **JavaScript (ES6)** → Consumo de API, lógica del programa y manipulación del DOM
* **API Colombia** → Fuente de datos
  https://api-colombia.com/

---

## ⚙️ Funcionalidades principales

* ✔ Consumo de datos en tiempo real con `fetch`
* ✔ Renderizado dinámico en el DOM
* ✔ Visualización mediante tarjetas (cards)
* ✔ Animaciones suaves al hacer scroll
